## 💡 Теория (Без пробелов)

### 1. Иерархия файловой системы Linux (FHS — Filesystem Hierarchy Standard)
В Linux нет дисков `C:`, `D:`. Всё представляет собой единое дерево, начинающееся с корневого каталога `/` (root).
Вот основные системные директории, которые админ должен знать наизусть:

- `/` — Корень всей файловой системы.
- `/bin` и `/sbin` (в современных дистрибутивах часто симлинки на `/usr/bin` и `/usr/sbin`):
  - `/bin` (binary) — базовые утилиты для всех пользователей (`ls`, `cp`, `cat`).
  - `/sbin` (system binary) — утилиты для администрирования системой (`fdisk`, `iptables`, `reboot`).
- `/etc` (et cetera / editable text configuration) — **конфигурационные файлы** всей системы и программ. Любые настройки (сети, пользователей, демонов) живут здесь.
- `/var` (variable) — изменяемые данные: логи (`/var/log`), базы данных (`/var/lib`), очереди печати/почты.
- `/usr` (user system resources) — установленные программы, библиотеки, документация.
- `/home` — домашние директории обычных пользователей.
- `/root` — домашняя директория суперпользователя `root`.
- `/tmp` — временные файлы (часто очищается при перезагрузке).
- `/dev` (devices) — файлы устройств (диски `/dev/sda`, терминалы `/dev/tty`, генераторы случайных чисел `/dev/urandom`, черная дыра `/dev/null`). В Linux "всё есть файл".
- `/proc` и `/sys` — **виртуальные файловые системы** (псевдо-ФС). Они не занимают место на диске, а являются окном в ядро Linux. Через `/proc` можно смотреть информацию о процессах и памяти (`/proc/meminfo`, `/proc/cpuinfo`), а через `/sys` — о железных устройствах и драйверах.

### 2. Потоки ввода/вывода (I/O Streams) и Перенаправление
У каждого процесса в Linux по умолчанию открыты 3 стандартных файловых дескриптора (FD):
1. **0 — stdin** (Standard Input, стандартный ввод) — по умолчанию клавиатура.
2. **1 — stdout** (Standard Output, стандартный вывод) — по умолчанию экран терминала.
3. **2 — stderr** (Standard Error, стандартная ошибка) — по умолчанию экран терминала для сообщений об ошибках.

#### Операторы перенаправления:
- `>` — Перенаправить stdout в файл (перезаписать файл).
  `echo "hello" > test.txt`
- `>>` — Перенаправить stdout в файл (дописать в конец).
  `echo "world" >> test.txt`
- `2>` — Перенаправить только stderr (ошибки) в файл.
  `ls /nonexistent 2> errors.log`
- `&>` или `> file 2>&1` — Перенаправить И stdout, И stderr в один файл.
- `<` — Перенаправить содержимое файла в stdin программы.
- `|` (Pipe / Конвейер) — Соединяет stdout одной команды со stdin другой команды.
  `cat /etc/passwd | grep bash`
